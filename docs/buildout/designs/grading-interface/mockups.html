Problem 9 ▾Could you design a CC that computes +1 B (i.e. unbounded)? Why or why not? Short paragraph.
Response 39of 74·submitted Oct 18, 10:14 pm·142 words

No. A combinatorial circuit has a fixed number of input wires, and it has to be built before it ever sees an input. So any CC can only read numerals up to some fixed length n.

+1 B has to work for binary numerals of every length. Whatever CC you build, there will be a numeral with more digits than it has input wires, and it can't compute the successor of that one. You can build a CC for +1 [0–n] B for each n (Problem 8), but no single CC does them all — that would need something like memory, which is what SCs add.
